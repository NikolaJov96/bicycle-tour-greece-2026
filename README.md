# Bicycle Tour — Greece 2026

A planning repository for a two-week road cycling trip in Greece, June 2026. Four riders, two cars, departing from Belgrade.

---

## How to Navigate This Repository

Each topic lives in its own file or folder. Click any link below to open it. If you are inside a folder, its own `README.md` will give you the same kind of index for what's inside. You can always click the repository name at the top of the page to come back here.

## Trip at a Glance

- **Dates:** June 13–28, 2026
- **Group:** 4 road bike riders, 2 cars from Belgrade
- **Format:** 2–3 bases with daily rides; one 4–5 day point-to-point segment
- **Terrain:** Mountains and hills, a few coastal days, tarmac only
- **Must-do:** Hike Mount Olympus (one rest day)
